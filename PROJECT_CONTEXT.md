## Design & State Conventions

### Theme System

Two themes controlled by a single CSS class on `<html>`:

- **Light (default, no class):** Champagne `#FBF8F2` background, oxblood `#A30000` primary, warm taupe `#4A4A4A` muted text, gold `#C9A84C` accent.
- **Dark (.dark class):** Near-black `#0A0A0A` background, neon red `#FF2020` primary, light grey `#CCCCCC` muted text, muted gold `#C9A84C` accent.

All colors defined as CSS custom properties in `:root` and `.dark` blocks in `app/globals.css`. Every component reads colors via `var(--color-*)` rather than hardcoded Tailwind classes. Tailwind v4 `@custom-variant dark` enables `dark:` prefix utilities.

**Theme state flow:**

1. `lib/theme-context.js` — `ThemeProvider` wraps children in `layout.js`.
2. On mount, reads `localStorage` key `r23_theme`, defaults to `'light'`.
3. `useEffect` toggles `.dark` class on `document.documentElement` and persists to localStorage.
4. `useTheme()` hook exposes `{ theme, toggleTheme }` to all client components.

| `--color-card-border` | `rgba(163,0,0,0.12)` | `rgba(255,255,255,0.05)` |

### Typography

- **Serif (wordmarks, headings):** Playfair Display (`font-[family-name:var(--font-serif)]`)
- **Sans (body, buttons, UI):** Inter (`font-[family-name:var(--font-sans)]`) — set as default on `<body>`

Relative units only — all sizes use Tailwind's rem-based classes (`text-7xl`, `text-sm`, etc.). No `px` font sizes.

### Accessibility Standards

- All interactive elements: `focus-visible:outline focus-visible:outline-2 focus-visible:outline-offset-2/4 focus-visible:outline-current`
- Hover states: non-color cues (`hover:scale-105`, `hover:-translate-y-0.5`, `hover:underline`, border thickness change 2px→3px)
- Subtitle text: `font-semibold` for low-vision readability
- aria-label on theme toggle: `"Toggle dark mode"`
- WCAG AA contrast targets met: subtitle `#4A4A4A` on `#FBF8F2` (~6.9:1), CTA `#FFFFFF` on `#A30000` (~7:1), dark mode CTA `#FFFFFF` on near-black background
- `prefers-reduced-motion` collapses all animations/transitions to 0.01ms

### Glow Effects

- `.neon-glow` — triple-layer box-shadow (7px/20px/40px) in `rgba(255,32,32,*)` — applied to dark mode CTA only
- `.neon-glow-text` — triple-layer text-shadow — applied to "ROOM 23" wordmark in dark mode with `dark:animate-pulse` (4s duration)

## Important Decisions

1. **No shadcn/ui** — This is a pure Tailwind CSS v4 project. All components are built from scratch with inline styles and Tailwind utilities.

2. **CSS variables over Tailwind color classes** — Instead of `bg-near-black` or `text-neon-red`, every component uses `style={{ color: 'var(--color-primary)' }}` etc. This enables clean theme switching via a single `.dark` class toggle without duplicating every component.

3. **All sections in one file** — `app/page.js` contains all 10 homepage sections as local function components (`HeroSection`, `ThreeColumnSection`, `TrustStrip`, `BrandPhilosophy`, `ProductCatalog`, `ItemOfTheMonth`, `TheColumn`, `VipWaitlist`, `ComplianceStrip`, `MinimalFooter`). No separate component files — keeps the prototype cohesive and easy to scan.

4. **Single-page static prototype** — No routing, no dynamic pages, no SSR data fetching. Everything is prerendered static content.

5. **No images** — All visual placeholders are CSS gradients or "Product Image / Coming Soon" text. The `products.js` data has `image: null` for every product, and `ProductTile` handles the null case with a fallback div.

6. **Theme defaults to light** — Changed from the original dark-only spec per user request. `useState('light')` and `storedTheme === 'dark' ? 'dark' : 'light'` ensure first-time visitors see the cream theme.

7. **Cloudflare compatibility** — `wrangler.jsonc` uses `compatibility_date: "2026-08-03"` with explicit `nodejs_compat` flag. The `2026-08-04` date made `nodejs_compat` built-in (removing the flag) which breaks OpenNext builds on Windows.

8. **Relative import paths** — Uses `../lib/theme-context` instead of `@/lib/theme-context` because the `@/` alias requires `jsconfig.json` which wasn't consistently resolving under the Cloudflare build pipeline.

9. **No cart/e-commerce logic** — The product catalog has "Add to Bag" buttons but they are visual only — no state, no cart context, no checkout. This is a design prototype, not a functional store.

10. **Branding** — Legal entity is "Room23 LLC" (not AW Holdings). Compliant with 18+ adult content requirements. Statement reads "Room23 LLC · Los Angeles, CA".
